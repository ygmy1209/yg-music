我想做一个本地的音视频播放器叫摇光音乐，仅服务于本地，先考虑能在Windows系统运行。本人对于Electron，better-sqlite3完全不懂，其他只是看过文档的程度，没实践过，需要你像教学生一样按课程完成项目。

一些开发要求： 1. 界面设计风格要现代化，年轻化，简约，充分灵活使用Animate.css。软件支持高度自定义化（后面设置有讲）。主题和字体要考虑全局。一些设置内容放在配置文件（我是看到参考项目是这么做的，我没写过项目不太懂），考虑持久化。
2. 本人代码水平很差，开发过程请保持代码优雅，规范，有良好写中文注释习惯。 
3. 遇到技术难题或一些工具技术使用不熟悉要善于联网学习相关知识，MCP可随意使用。 
4. 需要一步一步开发，要逐步验证。依赖配置不要直接写package.json文件,用npm命令安装即可。
5. 我的构想和框架只是初学者的理解和方向，你是专业的软件工程师，实际开发都听你的。
6. 运行npm run dev时提醒我，让我来运行。
7. 有用git提交的好习惯。
